# ChatNodeMisael

Proyecto de chat en tiempo real realizado por Misael Alexander.

## Abrir en Visual Studio Code

1. Descomprime la carpeta.
2. Abre `ChatNodeMisael` en Visual Studio Code.
3. Abre una terminal.
4. Ejecuta:

   npm install

5. Después ejecuta:

   npm start

6. Abre en el navegador:

   http://localhost:4000

## Desarrollo con Nodemon

npm run dev
